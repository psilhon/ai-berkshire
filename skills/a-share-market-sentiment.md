# A股市场情绪监测与仓位建议系统

本 skill 系统化判断 A股当前处于贪婪还是恐惧状态，基于 5 个核心指标给出情绪评级与仓位调整建议。

> 定位说明：本 skill 是**市场级**能力，独立于 13 单元单公司契约（`tools/full_analysis_contract.json`）。与 `macro-liquidity`（流动性监测）互补：流动性回答"钱够不够"，本 skill 回答"人有多疯/多怕"。同一批数据（两融/北向）在两处解读视角不同，不重复。

> 来源移植：框架（5 指标 + 预警计数 + 分档建议）取自外部项目 Day1Global-Skills `us-market-sentiment`（MIT）；原版 NAAIM/机构配置/散户净买/S&P Forward PE/对冲基金杠杆为美股口径，在 A股全部不可用，本 skill 整体替换为 A股可落地口径并补本项目纪律。

## 两条底线（与全项目一致）

1. **真实数据**：每个指标取真实最新值并声明数据日期与来源；取不到就显式标记"数据不足"，绝不猜测、绝不编造。
2. **失败显式声明**：任何指标取数失败，按 fail-close 规则写入报告"数据缺口"节；不静默跳过。

## 指标总览（5 指标，预警计数制）

| 指标 | 口径 | 取数 | 含义 |
|------|------|------|------|
| S1 两融余额趋势 | 融资余额 5/20 日变化 | `ashare_data.py margin`（Tushare） | 杠杆资金风险偏好 |
| S2 北向资金 | 连续净流入/流出与累计额 | `ashare_data.py hsgt-flow`（Tushare） | 外资边际动向 |
| S3 指数估值分位 | 沪深300 PE/PB 近5年分位 | `ashare_data.py index-val hs300`（Tushare） | 估值贵贱（逆向锚） |
| S4 换手率与成交热度 | 全市场换手/两市成交额 | WebSearch（东财/新浪）；热度榜 `ths-hot` 旁证 | 交易活跃度 |
| S5 新开户与基金发行 | 新增开户数/偏股基金发行 | WebSearch（中国结算/东财） | 散户入市意愿 |

**预警计数制**：5 个指标各自独立判"出警/正常"，统计出警数映射评级与建议（见"合成逻辑"）。权重仅用于出警时对总评的贡献排序，不精确打分。

## S1 两融余额趋势（杠杆水位）

**定义**：融资余额是杠杆资金的风向标。余额快速上升=杠杆资金追涨（情绪升温）；快速下降=去杠杆（恐慌）。**看趋势不看单日**。

**取数**（须交易日，周六日/节假日无数据属正常）：
```bash
python3 tools/ashare_data.py margin --date 20260807
# 输出：融资余额=XXXX亿 融券余额=XXX亿
# ⚠️ 必须显式传 --date（YYYYMMDD 最近交易日）；不带日期会返回 empty_data 失败
```
数据来源：Tushare margin（TUSHARE_TOKEN 已配置于环境）。参考：融资余额突破 2 万亿并加速上行通常对应情绪高位（2021/2015 经验区）。

**出警标准**：
- 🔴 融资余额 5 日累计增幅 >3% 且 20 日趋势陡峭上行：杠杆追涨过热
- 🔴 融资余额 5 日累计降幅 >3%：去杠杆恐慌
- 🟡 温和上行/下行：关注
- ✅ 平稳：正常

**趋势取数（5/20 日对比）**：本工具仅支持单日查询，逐日调用成本高（20 日趋势 ≈ 20 次调用）。替代路径（按优先级）：
1. WebSearch `两融余额 融资余额 近一月 走势`（东财数据中心/同花顺周报），取周度或月度序列。
2. 本地工具只取最近 2 个交易日做 5 日近似，并在报告标注"趋势粒度=日级近似"。
3. 无法取得历史序列时 → 该指标只按最新值判单日信号，趋势判定进"数据缺口"节说明，不静默跳过。

**注意与 `macro-liquidity` 的分工**：本指标在此解读"情绪"，在 macro-liquidity 中解读"流动性水位"；两份报告可以并存，同一数据两处引用时须保持数值一致。

## S2 北向资金（外资动向）

**定义**：沪深港通北向净流入。连续大额净流出=外资系统性撤退（风险偏好下降）；持续净流入=外资风险偏好抬升。注意：北向盘中数据不实时披露，以日终成交数据为准（本工具即日终值）。

**取数**：
```bash
python3 tools/ashare_data.py hsgt-flow --date 20260807
# 输出：北向资金净流入=XX亿 南向=XX亿
```
数据来源：Tushare moneyflow_hsgt。

**出警标准**：
- 🔴 连续 5 日净流出且累计 >100 亿：外资系统性撤退
- 🔴 连续 10 日净流入且累计 >300 亿：外资亢奋追涨（情绪高点风险）
- 🟡 单日大额净流出（>100亿）或连续 3 日同向：关注
- ✅ 净流入/小幅流出：正常

## S3 指数估值分位（逆向锚）

**定义**：沪深300 当前 PE/PB 在近 5 年中的历史分位。这是**逆向指标**：分位越高市场越贵（贪婪），分位越低越便宜（恐惧/机会）。机构常"越高越乐观、越低越悲观"，恰恰是反向信号。

**取数**：
```bash
python3 tools/ashare_data.py index-val hs300
# 输出：沪深300 PE/PB 及历史分位
```
数据来源：Tushare index_dailybasic。其他指数别名：hs300/zz500/sse/cyb。

**出警标准**：
- 🔴 PE 分位 > 85%：估值高位，情绪贪婪
- 🟡 PE 分位 70-85%：偏贵，关注
- ✅ PE 分位 < 70%：正常
- 📉 PE 分位 < 15%（配合市场恐慌）：历史性低估区——逆向看是机会区，需与基本面验证（本指标只报情绪，不单独构成买入信号）

## S4 换手率与成交热度（交易活跃度）

**定义**：全市场换手率/两市成交额反映交易活跃度。成交持续天量=换手狂热（情绪顶点特征）；成交萎缩=观望/恐惧。参考经验：两市成交额持续 2 万亿+ 并放大通常对应情绪高位，持续低于 8000 亿对应低迷。

**取数**（按优先级）：
1. WebSearch `两市成交额 今日` / `A股 换手率`；一手源：交易所官网（上交所/深交所）、东财行情页。
2. 旁证：`python3 tools/ashare_data.py ths-hot --period day`（同花顺热榜/东财人气榜，零依赖）观察热度题材扩散度——热榜被单一题材霸榜且极度拥挤时是情绪过热的定性旁证。

**出警标准**：
- 🔴 成交额持续天量（相对近 1 年均值放量 >80%）且换手率创阶段新高：换手狂热
- 🟡 温和放量：关注
- ✅ 常态区间：正常
- 📉 成交持续地量（低于近 1 年均值 50%）：恐慌/无人问津——逆向观察区

## S5 新开户与基金发行（散户入市意愿）

**定义**：新增开户数（中国结算月度发布）与偏股基金发行规模反映散户与增量资金入市意愿。开户激增/基金发行火爆=增量资金涌入（情绪狂热特征，历史上常出现在阶段性高点附近）；开户冰点/基金发行遇冷=情绪冰点（逆向看是机会区）。

**取数**：WebSearch `新增开户数 中国结算` / `偏股基金 发行 规模`；一手源：中国结算（chinaclear.cn）、东财基金数据。

**出警标准**：
- 🔴 月度新增开户环比激增（>+50%）或偏股基金单月发行显著放量：散户狂热
- 🟡 温和抬升：关注
- ✅ 常态：正常
- 📉 开户冰点/基金发行困难：情绪冰点——逆向观察区

> 数据可得性提示：中国结算月度数据滞后约 3-4 周，属**滞后指标**，仅作旁证，不作为主信号；取不到最新月时用最近可得月数据并注明日期。

## 合成逻辑（双向出警计数 → 评级 → 建议）

**统计方向性出警**：每个指标可能发出**贪婪信号（+1）**或**恐慌信号（-1）**，各自独立计数。贪婪信号总数=出警数中偏向贪婪的数量；恐慌信号总数=偏向恐慌的数量。**方向不可混淆：恐慌信号绝不并入贪婪计数。**

各指标的信号方向：
| 指标 | 贪婪信号（+1） | 恐慌信号（-1） |
|------|--------------|--------------|
| S1 两融 | 5 日升 >3% 追涨过热 | 5 日降 >3% 去杠杆 |
| S2 北向 | 连续 10 日净流入累计 >300 亿 | 连续 5 日净流出累计 >100 亿 |
| S3 估值分位 | PE 分位 >85%（贪婪） | PE 分位 <15%（恐慌，📉 逆向机会区） |
| S4 成交热度 | 天量放量（贪婪） | 持续地量（恐慌，📉 逆向观察区） |
| S5 散户入市 | 开户/基金发行激增（贪婪） | 开户冰点/发行困难（恐慌，📉 逆向观察区） |

**评级映射（先看恐慌，再看贪婪）**：
| 恐慌信号数 | 贪婪信号数 | 情绪评级 | 仓位建议 |
|-----------|-----------|---------|---------|
| ≥3 | 任意 | 😨 恐慌 | 逆向加仓观察区：分批加仓须基本面验证 |
| 2 | 贪婪 ≤1 | 📉 偏恐慌 | 关注超跌反弹机会，控制仓位 |
| 1 | 贪婪 ≤1 | 📊 中性-谨慎 | 维持当前仓位，跟踪趋势 |
| 0 | 0-1 | 📊 中性 | 维持当前仓位 |
| 0 | 2 | 📊 中性-乐观 | 可小幅调整，注意风控 |
| 0 | 3 | 🟡 贪婪 | 减仓信号：考虑降低权益仓位 10-20% |
| 0 | 4 | 🔴 极度贪婪 | 明确减仓：考虑降低权益仓位 20-30% |
| 0 | ≥5 | 🔴🔴 极度贪婪（全警） | 显著减仓或建立对冲仓位 |

**合成规则（fail-close）**：
1. 指标取不到真实数据 → 计为"数据缺口"，**不计入任何方向计数**，在报告"数据缺口"节显式列出。
2. 方向计数按"有数据的指标"统计，报告须注明"基于 X/5 个指标"。
3. **全部指标数据不足 → 不产出评级**，直接输出失败声明（含原因）。
4. 恐慌信号与贪婪信号同时出现（如两融降+估值高位）→ 按表分别计数后取更高等级方向；若两者等级相同，输出"多空信号并存"并提示需结合基本面裁决。
5. 情绪评级是**背景层**不是决策本身：任何仓位建议都必须与 `macro-liquidity` 评级、个股基本面（`investment-research` 等）交叉引用后才可执行；本 skill 单独不构成买卖指令。

## 执行步骤

1. 本地 `date` 确认今日日期，作为报告基线。
2. 🔴 **STOP / 检查点**：在启动任何外部取数（本地工具或 WebSearch）前，必须先向用户确认（给出明确选项：如"确认按规范取数""仅先列数据清单不抓取"），获得明确同意后再继续；未经确认不得自主发起外部取数（对齐 `skills/financial-data.md` STOP 检查点）。
3. 逐指标取真实值 → 按出警标准判定 → 记录数据日期与来源。
4. 统计出警数（有数据的指标）→ 映射情绪评级与仓位建议。
5. 🔴 **STOP / 检查点**：在将完整报告交付给用户前，必须先向用户确认（给出明确选项：如"确认输出完整情绪报告""仅输出指标看板不含建议"），获得明确同意后再输出最终版；报告须含三锚（数据截止日/来源/免责）齐全方可交付。
6. 联动：与 `macro-liquidity` 评级交叉引用；个股层面联动 `news-pulse`（异动归因）。

## 关键原则

- **取不到就说取不到**：任何指标数据缺口都写进"数据缺口"节，绝不静默跳过、绝不编造数值。
- 看趋势不看单日：出警标准都基于趋势/累计变化，单日波动不构成信号。
- 情绪指标是**反向参考**：极端贪婪往往对应风险，极端恐慌往往对应机会；但"往往"不是"必然"，必须与流动性/基本面交叉验证。
- 报告必须含三锚：数据截止日 + 来源声明 + 免责声明，缺一不可。

## 反例与红线（不要做）

- ❌ 数据取不到时填"约 X"或从训练记忆编数值 → 违反底线 1
- ❌ 单指标出警就下"马上减仓"结论 → 出警只看计数，决策须交叉验证
- ❌ 把"估值分位 <15%"直接当"买入信号" → 情绪指标只报情绪，不单独构成买入指令
- ❌ 周六/节假日跑 `margin` 报错后判定"数据不足"并中止整个报告 → 非交易日属正常，改用最近交易日
- ❌ 把美股口径指标（NAAIM/Forward PE 等）硬套 A股 → 口径不同，禁止混用

## 失败处理（如果 X 失败 → Y）

- Tushare 接口空数据（margin/hsgt-flow/index-val）→ 标注接口+日期，改用最近交易日重试一次；仍失败则进"数据缺口"，不阻塞其他指标
- WebSearch 取不到新开户/基金发行最新值 → 用最近可得月数据并注明日期；仍取不到则进"数据缺口"
- 未配置 TUSHARE_TOKEN → 相关指标按缺口处理，其余指标照常
- **全部指标数据不足 → 报告不产出评级**，直接输出失败声明（含原因），不合成结论
