# 行业投资研究：产业链全景 + 漏斗精选一体化流程

对 $ARGUMENTS 行业/投资方向执行系统化研究。本 skill 合并自原 `industry-research`（产业链全景）与 `industry-funnel`（个股漏斗精选）：两者是同一投研流程的前后两半，此处按统一方法论串成一条主流程，按需选择深度模式，不再拆成两个入口。

## 运行模式（开始前先定，模式不符时向用户确认）

| 模式 | 适用意图 | 覆盖步骤 | 终点产物 |
|------|---------|---------|---------|
| **A 全景** | "看懂这个行业 / 格局如何" | 第 1-5 步（到精细档）+ 第 7 步（跳过第 6 步个股组合） | 产业链全景 + 环节评级 + 行业风险/文明趋势/收尾自评，不收敛个股 |
| **B 精选**（默认推荐） | "在这个行业里选标的" | 第 1-7 步全程 | 终选 3 家 + 组合配置 |

模式 A 可随时升格为 B（用户追问"那该买谁"时，从第 5 步深析档继续第 6、7 步）。用户在输入时未表明意图 → 列出两种模式请用户选择，不默认替用户决定荐股。

## 流程总览

```
① 投资逻辑链构建与验证        底层趋势→需求→瓶颈→受益链，逐环证伪
        ↓
② 产业链全景图绘制            上游→中游→下游→辅助，标注卡脖子环节
        ↓
③ 全球上市公司扫描建池        环节 × 市场（A/港/美/国际/未上市），Tier 分层
        ↓ 5 条价值硬指标 + 护城河门槛
④ 去劣筛选                    池 → ≤ 10 家（淘汰必留理由，不黑箱）
        ↓
⑤ 分层四大师分析              各环节 Tier1/2 精细档；深析档仅 B（A 止于精细档）
        ↓
⑥ 终选 3 家与组合配置（仅 B）   组合互补性终选 + 核心/卫星/期权仓位 + 信号
        ↓
⑦ 行业级收尾（A 与 B）        行业风险 / 历史类比 / 文明趋势 / 决策备忘录
```
（模式 A 走 ①②③④⑤→⑦，跳过 ⑥；模式 B 走 ①→⑦ 全程。）

每层"过滤掉的标的"必须留下淘汰理由；本流程所有结论均须标注数据来源与信心度。

## 第一步：投资逻辑链构建与验证

### 1.1 画出逻辑链
用箭头链路表达从"底层趋势"到"受益标的"的因果关系，例如：
```
底层趋势 A
    → 导致需求 B
        → 创造瓶颈/刚需 C
            → 受益产业链 D
```

### 1.2 逐环节验证
对逻辑链的每个箭头提出质疑并寻找证据：

| 环节 | 核心假设 | 验证方式 | 数据来源 |
|------|---------|---------|---------|
| A→B | | 搜索行业数据/预测 | |
| B→C | | 搜索供需分析 | |
| C→D | | 搜索实际案例/签约 | |

### 1.3 寻找"已发生的验证事件"
列出支撑该逻辑链的**已签约/已落地的真实商业事件**（而非预测），例如大公司的采购协议、政策文件、行业报告等。只有验证事件支撑的环节才可进入下一步。

---

## 第二步：产业链全景图绘制

### 2.1 绘制产业链结构
将行业拆解为上游→中游→下游→辅助环节，例如：
```
上游：原材料/资源开采 → 材料加工/提纯
中游：核心设备制造 → 系统集成/工程建设 → 新技术研发
下游：运营/服务 → 终端客户
辅助：检测/认证 → 维护服务 → 金融工具（ETF/信托）
```

### 2.2 识别每个环节的"生意特征"
| 环节 | 商业模式 | 毛利率区间 | 竞争格局 | 壁垒类型 | 周期性 |
|------|---------|-----------|---------|---------|--------|
| | 卖资源/卖设备/卖服务/收租 | | 垄断/寡头/充分竞争 | 资源/牌照/技术/规模 | 强/中/弱 |

### 2.3 标记"卡脖子环节"
识别产业链中供给最紧张、替代最难、利润率最高的环节——这些往往是最佳投资标的所在。若信息不足识别不出，**显式声明"卡脖子不明确"**并按标准覆盖各环节，不得强行指定某环节装点门面。

## 第三步：全球上市公司扫描建池

🔴 STOP / 检查点：在启动全市场扫描（后台 Agent 或 WebSearch 各市场抓取候选标的）前，必须先向用户确认（给出明确选项：如"确认开始全市场扫描""仅先规划扫描清单不取数"），获得明确同意后再继续；未经确认不得自主发起外部检索。

### 3.1 扫描协议（环节 × 活跃度 × 市场）
以第二步产业链环节为骨架组织扫描结果，同时对每个环节用三类并集防止漏掉活跃标的：

**活跃增强（A ∪ B ∪ C）**：
- **A 类 - 成交活跃度**：近 30 天日均成交额排名行业前列（A 股/港股/美股各自取前 30）
- **B 类 - 涨幅榜**：近 30 天涨幅前 20 ∪ 近 90 天涨幅前 20
- **C 类 - 市值锚定**：行业内市值前 30（无论涨跌）

### 3.2 必须覆盖的市场
| 市场 | 来源建议 |
|------|---------|
| A 股（沪深） | Tushare `peers`/同花顺/东方财富行业板块 |
| 港股 | 富途/同花顺港股、HKEX 行业分类 |
| 美股 | NASDAQ/NYSE 行业 ETF 持仓、Yahoo Finance |
| 国际市场 | 日韩台欧相关公司不能漏（特别是半导体、电子） |
| 未上市公司 | 单列"未来 IPO 候选"，注明最新估值与潜在 IPO 时间 |
| 行业 ETF | 记录 1-3 只备选（第六步 ETF 替代用） |

### 3.3 对每家公司采集
- 公司名称（中英文）、代码、交易所、市值（近似）
- 一句话描述（在产业链中的位置和作用）
- **纯正度**：是否纯正标的（行业收入占比；< 30% 的"沾边股"标注"非纯正标的"）
- **产业链所属环节** + 入选类别（A/B/C）
- **Tier 分层**（按投资确定性，非精确排名）：
  - **Tier 1**：大市值、纯正标的、行业龙头
  - **Tier 2**：中市值、纯正或高占比、细分龙头
  - **Tier 3**：小市值、开发阶段、高风险高弹性
  - **Tier 4**：多元化公司中有相关业务的大型企业

### 3.4 输出格式
按产业链环节分类，每环节一张表（含入选类别与 Tier），末尾单列"未来 IPO 候选"小节。

**扫描自查**：中国/亚洲市场不要因英文资料少而漏；小市值不要因 AI 偏好龙头而漏；未上市公司必须单列，不得只扫上市公司。

## 第四步：价值 5 条硬指标去劣 → ≤ 10 家

对扫描池中 Tier 1-3 公司（Tier 4 多元化公司通常直接降为观察）逐家应用 5 条硬指标。

### 4.1 5 条硬指标
| # | 指标 | 通过标准 | 放宽条件 | 数据来源 |
|---|------|---------|---------|---------|
| 1 | PE 估值 | 合理（与历史区间、同业对比） | 高成长可放宽到 PEG < 1.5 | 财报 + Tushare `industry-pe` 分位 |
| 2 | ROE | > 15% 或近 3 年趋势改善 | 重资产行业可放宽 | 财报 |
| 3 | 经营现金流 | 为正且占净利润 > 70% | — | 财报 |
| 4 | 资产负债率 | < 60% | 公用事业/电力可放宽至 70% | 财报 |
| 5 | 护城河快评 | ★★★ 以上 | — | 定性判断（护城河五类见 5.2） |

### 4.2 保留规则（淘汰必留痕）
- 5 条全部及格 → 直接保留
- 4 条及格 + 1 条接近 → 保留但标黄
- 不足 4 条 → 淘汰，注明理由

**目标**：保留 ≤ 10 家。保留过多（> 12）→ 护城河标准提到 ★★★★ 再筛一次。

### 4.3 输出格式
| 公司 | 环节 | Tier | PE | ROE | 现金流/净利 | 负债率 | 护城河 | 留/弃 | 淘汰理由 |
|------|------|------|----|----|-----------|-------|-------|------|---------|

## 第五步：分层四大师分析

对第四步保留的标的执行大师框架分析，**深度按档位**（不是每家公司同篇幅）。**模式 A 执行到精细档即止步，不进入深析档**（深析档只服务模式 B 的终选环节；A 升格 B 时从深析档继续）：

| 档位 | 适用对象 | 篇幅 | 模式 |
|------|---------|------|------|
| 快评 | Tier 3/4、已淘汰但需留痕者 | 100-200 字/家 | A + B |
| **精细档** | 各环节 Tier 1/2、第四步保留者 | 300-500 字/家 | A（止步点）+ B |
| **深析档** | 终选 3 家候选 | 800-1200 字/家 | 仅 B |

精细档与深析档共用同一套大师维度（5.1-5.6），仅深度与证据密度不同。每个分析模块末尾保留对应大师的"追问"。

### 5.1 生意本质（段永平）
- 一句话定义这家公司在产业链中做什么（卖什么、卖给谁、怎么收钱）
- 收入结构与增速；毛利率/净利率水平及趋势；现金流特征
- **追问**：这是一门好生意吗？为什么？"本分"是什么，管理层有没有偏离？商业模式的持续性在哪？

### 5.2 护城河（巴菲特）
五类护城河评分（★1-5），列具体证据：

| 护城河 | 强度 | 具体证据 |
|-------|------|---------|
| 品牌/定价权 | | |
| 转换成本/用户黏性 | | |
| 网络效应 | | |
| 规模效应 | | |
| 技术/牌照/资源壁垒 | | |

**追问**：10 年后护城河还在吗？现在买入的"安全边际"在哪？

### 5.3 风险（芒格）
- 这家公司最可能怎么失败？（列出前 3 失败路径）
- 最坏情景下值多少钱？（极简估值）
- 聪明人为什么不买？（反向论证）
- 是否有道德/合规/管理层风险？

### 5.4 管理层专项（段永平 + 巴菲特）
- CEO/创始人是谁？关键决策记录
- 持股比例与利益对齐
- 简评（A/B/C 级：A=可信赖且利益对齐；B=一般；C=有红旗需警惕）

### 5.5 文明级趋势定位（李录，个股层）
- 所在赛道是"文明级范式转移"还是"阶段性热潮"？
- 历史上最接近的技术革命类比？
- 10-20 年后这家公司的终局？是不是赢家通吃格局？

### 5.6 估值快照与推荐度
- 当前 PE/PS/EV/EBITDA + 历史区间位置 + 同业对比 → 一句话：贵 / 合理 / 便宜
- 推荐度 ★1-5 定义：★★★★★=核心仓位候选 / ★★★★☆=卫星 / ★★★☆☆=观察 / ★★☆☆☆=高风险期权 / ★☆☆☆☆=不推荐
- 综合推荐块（深析档必填）：
```
推荐度：★★★★☆
仓位类型：核心 / 卫星 / 期权 / 观察
建议买入区间：当前价 / 回调 N% / 有耐心等待
建议持仓比例：占该主题仓位 X%
关键监测指标：（逻辑一旦反转的信号是什么）
```

## 第六步：终选 3 家与组合配置

🔴 STOP / 检查点：在输出终选标的的推荐度、仓位类型、建议买入区间与持仓比例等强结论前，必须先向用户确认（给出明确选项：如"输出完整配置建议""仅输出中性分析不荐股"），获得明确同意后再继续；未经确认不得自主替用户决定投资方向与仓位。

### 6.1 终选标准（组合互补性，非打分排序）
- 至少 1 家"高确定性低弹性"（巴菲特型）
- 至少 1 家"中等确定性中等弹性"（成长型）
- 可选 1 家"高弹性高风险"（期权型）
- **宁缺毋滥**：某子赛道找不到 3 家足够好的，写"终选 2 家 + 1 家观察"，不得凑数。

### 6.2 推荐组合表
| 层级 | 仓位占比（占主题） | 标的 | 所属环节 | 类型 | 推荐度 | 核心逻辑 | 关键风险 |
|------|---------|------|---------|------|-------|---------|---------|
| 核心 | 50-60% | | | 高确定低弹性 | | 最确定、护城河最宽 | |
| 卫星 | 25-35% | | | 中确定中弹性 | | 弹性较大、确定性稍低 | |
| 期权 | 5-15% | | | 高弹性高风险 | | 高风险高回报，可归零 | |
| ETF 替代 | 可替代以上全部 | | | — | — | 不想选股的"懒人方案"，列 1-3 只 | |

### 6.3 整体行业位置判断（位置决定仓位）
- 行业 PE/PB 历史分位（Tushare `industry-pe`）
- 资金流向（北向、ETF 申赎、板块资金 `sector-flow`、卖方覆盖密度）
- 行业处于"早期/扩张/成熟/衰退"哪个阶段

### 6.4 买入/卖出信号
| 信号类型 | 具体条件 |
|---------|---------|
| 加仓信号 | |
| 减仓信号 | |
| 清仓信号 | |

主题仓位上限：按逻辑链确定性与风险程度给出该主题占总仓位的上限建议。

## 第七步：行业级收尾

> 模式取用：**A 与 B 都执行本步**（行业级结论，不依赖个股收敛）。A 模式跳过第 6 步后直接落到本步；本步不产出个股推荐。

### 7.1 行业级风险清单（芒格"检查清单"）
| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|---------|
| 投资逻辑链的某个环节被证伪 | | | |
| 替代技术出现 | | | |
| 政策/监管黑天鹅 | | | |
| 需求周期性回调 | | | |
| 估值泡沫破裂 | | | |

**历史类比**：找历史上类似的产业链投资主题分析结局——类比行业？最终赢家在上/中/下游哪环？多数投资者赚还是亏？对当前行业的启示？
**偏误自查**：叙事偏差（故事是否太完美）/ 锚定效应（是否被近期涨幅锚定）/ 从众效应（是否因为"所有人都在买"）。

### 7.2 文明趋势终判（李录，行业层）
- 行业依托的底层趋势是"文明级范式转移"还是"阶段性热潮"？
- 历史上最接近的技术革命类比？
- 10-20 年后行业终局？哪个环节最可能"赢家通吃"？哪个环节最可能被颠覆？

**四位大师模拟点评**：用引用格式，模拟四位大师对该行业投资机会的点评。

### 7.4 信息充分度自评（必填）
| 维度 | 等级 | 说明 |
|-----|------|-----|
| 公司财务数据完整性 | A/B/C | |

明确列出：哪些数据是估计值、哪些需要后续核实、哪个季度财报需重点跟踪。

### 7.6 资料来源清单
每个数据/结论的来源链接，分类列出（财报、研报、新闻、行业报告）。

## AI 研究偏见自觉（重要）

行业研究 + 个股筛选全过程，AI 容易踩的坑（发现新偏见时补充本表）：

| 偏见 | 表现 | 应对 |
|------|-----|------|
| 龙头偏好 | 大市值公司资料多、分析篇幅长，看起来"更好" | 按硬指标与护城河打分，不按报告篇幅排序；不因分析短就降推荐度 |
| 英文偏好 | 美股资料丰富，A 股港股易被低估 | 必须中英文都搜，A/H 公司不能漏 |
| 上市偏好 | 只看上市公司可能错过赛道最好的玩家 | 必须列"未来 IPO 候选"，标注估值与时间窗/信息 C 级 |
| 故事偏好 | 高涨幅 + 媒体热度 = 看起来更好的"AI 概念股" | 区分"AI 收入占比" vs "AI 故事占比"，看真实业务 |
| 当下偏好 | 当前财务好的公司容易入选，错过转型期黑马 | 第 4 步允许"趋势改善"作为放宽条件 |
| 成熟行业偏好 | 传统行业资料极多，AI 分析看起来"更确定" | 确定性来自商业模式，不来自研报数量 |
| 新兴行业低估 | 新行业资料少，AI 分析偏保守 | 用"终局思维"而非"当前数据"判断行业价值 |

**反偏见措施**：① 每环节除"AI 容易找到的公司"外，主动搜"冷门但可能优质的标的"；② 信息稀缺的小市值公司用核心问题（生意本质/护城河/管理层）评判，不因篇幅短降级；③ 最终报告标注每家公司信息充分度（A/B/C），让读者知道可靠程度。

1. **报告位置**：`local/reports/{行业名}-industry-analysis-{YYYYMMDD}.md`（行业报告放 local/reports/ 根目录）
2. **语言**：中文；**风格**：直接、犀利、不说废话
3. **数据**：所有数据标注来源；估计值标"估计"；取不到的标"未知/暂缺"，不编造
4. **不预设立场**：先摆数据 → 推逻辑 → 出结论；每个核心判断附反面论据
5. **全景图与逻辑链**用代码块文本图；关键数据用 Markdown 表格
6. **淘汰留痕**：被淘汰的公司留名字 + 理由
7. **覆盖要求**：全景模式不写成"索引式速览"——须突出卡脖子环节与最佳投资环节
8. 结论要明确（标的/仓位/价格区间），但**是否给到强结论由模式与 STOP 门决定**

## 数据抽检（准出流程）

报告写入后，执行数据抽检，通过方可发布：

```bash
# Step 1 — 提取抽检清单（15% 随机抽样）
python3 tools/report_audit.py extract \
  --report <报告文件路径>

# Step 2 — 对清单每项从可靠信源取数（参见 skills/financial-data.md）

# Step 3 — 输出三态判决（准出/证据不足/打回）
python3 tools/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report <报告文件名>
```

**【准出】** 全部抽检点双源核验通过 → 可发布；**【证据不足】** 有未核验/单一来源/两源冲突点 → 补齐第二来源后重跑；**【打回】** 有不通过 → 修正后重审。

🔴 STOP / 检查点：在跑 `report_audit.py` 准出并对外发布报告前，必须先向用户确认（给出明确选项：如"确认发布""仅生成草稿待审阅"），获得明确同意后再继续；未经确认不得自主发布。

## 反例与红线（不要做）

- 不要用单一信源下行业/筛选结论：任一产业链/公司/估值判断须至少双源交叉验证；每层留弃标准可复盘，淘汰标的留名字+理由，不得黑箱。
- 不要编造公司或数据：扫描不到的公司、取不到的财务数字标"未知/暂缺/未来IPO候选"，严禁估算后伪装真实数据。
- 不要遗漏重要市场与未上市玩家：日韩台欧、未来 IPO 候选必须单列；不得因英文资料少漏掉 A/H 公司。
- 不要因资料多就偏好成熟行业/龙头，也不因分析短就降小市值标的的推荐度。
- 不要跳过 5 条硬指标与护城河 ★★★ 门槛给高分：门槛不可为叙事放宽。
- 不要凑数到 3 家：找不到足够好的宁可"终选 2 家 + 1 家观察"。
- 不要平均用力写成"索引式速览"：须突出卡脖子环节与最佳投资环节。
- 不要把 Tier 分层当精确排名：Tier 1-4 是投资确定性分层，不是打分排序，不得据此声称"某公司优于某环节"。
- 不要跳过 `tools/report_audit.py` 数据抽检直接发布：【证据不足】/【打回】须补齐或修正后重跑。
- 不要在用户未授权时落盘或对外发布：写入 `local/reports/` 与准出须经 🔴 STOP 检查点。

## 失败处理（如果 X 失败 → Y）

- 如果 后台扫描 Agent 超时/拒答 → 执行：降级为主代理直接按中英文源搜索并明确告知"部分数据由主代理补充"，不静默跳过。
- 如果 WebSearch/WebFetch/数据源超时、限流或无结果 → 执行：换中英文源或 curl 直连东财/巨潮重试，仍无料标"数据不足"，不编造。
- 如果 某家/某环节财务、估值数据取不到 → 执行：该标的信息充分度自评降为 B/C，结论标注"需谨慎"，必填字段不跳过。
- 如果 `report_audit.py` 判【证据不足】/【打回】→ 执行：补齐第二来源或修正后重跑，不绕过审计发布。
- 如果 用户输入含糊（未指定行业/方向，或未说明模式）→ 执行：列出 2-3 个可能解读/两种模式请用户澄清，不在未确认时自选展开。
- 如果 投资逻辑链某环节被证伪 → 执行：回退重估下游受益标的，标注"逻辑链已弱化/失效"，不继续按原链推演。
- 如果 识别不出"卡脖子环节" → 执行：显式声明"卡脖子不明确"，按标准覆盖各环节并降级信心度。
- 如果 未上市公司信息极度稀缺 → 执行：标"未来IPO候选/信息C级"，列需一手验证的问题清单，不推测填满框架。
