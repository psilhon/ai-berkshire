兼容 Claude Code 与 Codex 的价值投资研究 Skill 合集：把巴菲特 / 芒格 / 段永平 / 李录四大师方法论沉淀为 17 个可复用研究 Skill + 金融严谨校验工具。 本文档替代 docs/architecture-and-skills-guide.html（v3.9.1 版，保留为历史档案）。完整 Skill 规范以 SKILLS-GUIDE.md 为唯一真源。

1 · 架构总览：单源双镜像 + lean-v1 编排管线

单源双镜像
只改 skills/*.md，两个同步脚本生成副本；改后必须双同步 + check.sh。三副本一致性由守卫测试钉死，不可物理合并。
lean 最小纪律
无 watchdog/租约/波次错峰。失败必须显式 mark-failed --reason；报告是唯一交付物，空证据账本合法，绝不合成 PLACEHOLDER。
两条底线
① 内容质量（结论影响实盘，完整性/正确性/内部一致不可协商）；② 失败必须显式声明，不静默跳过。

2 · 全量分析管线：13 单元依赖图（full-analysis-contract/lean-v1）

执行入口：python3 scripts/full_analysis.py start --code 600519.SH（或对话触发「全量分析 贵州茅台」）。 每单元产出报告 + 可选证据账本；L1 主线 = 13 份报告 → deep-summary 熔炼 → register-summary 冻结 → render-html 确定性交付。 L2-L4（audit/review/finalize+doctor）为可选评估层，只校验准出、不改内容。

4 · 数据源分层与冲突裁决

层级数据源性质使用规则
Tier 0Tushare Pro（付费，需 TUSHARE_TOKEN）独立结构化、可审计可冻结，47 命令最高优先级：冲突时以 Tushare 为准
Tier 1腾讯行情 + 东方财富 + 巨潮（免费零 token）基础层，curl 直连实时行情/核心财务/公告/打板三件套；价格双源验证（腾讯+新浪）
Tier 2WebSearch / WebFetch非结构化、不可冻结仅 Tier 0/1 无法覆盖时使用（行业定性/管理层/竞对）
Tier 3financial_rigor.py / report_audit.py确定性计算与审计Decimal 精确验算、三情景建模、报告质量门
冲突解决（v3.9.3 双源冲突协议）：价格类 CONFLICT 自动以 Tushare 覆盖；财务类（期间/单位/口径不一致）不自动覆盖、标注双源差异；取数型 skill 差额 >20% 触发 ⚠️ 默认采信权威源、双值并列展示、禁止静默通过。零依赖层无日K/OHLC：kline（需 token）或 tools/akshare_data.py price（零 token，腾讯前复权）。

7 · 核心约定速记

  • 数据截止日：研究前先 date 确认今日作为基线，报告头标注截止日 + 仅供学习研究免责。
  • 低置信标注：低置信结论、不完整数据、信源缺口必须显式标注，不静默。
  • 隐私边界：local/ 与 deliverables/ 仅本地不入库（公开仓库）。
  • 报告语言：简体中文；数字溯源可复核；禁止凑数式注水（深度优先于字数）。
  • 写后自查：每次用业务 skill 产出后，对照该 skill 末尾执行检查清单逐项勾选；标「强制/必须」的步骤禁止降级省略。
