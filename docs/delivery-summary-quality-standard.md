# 交付总结（delivery-summary）质量标准

> 适用对象：`full-company-analysis-workbuddy` 收口阶段产出的
> `<run_root>/evidence/attempts/summary/summary.md`（经 `register-summary` 冻结为
> `<公司>-全量分析-总结报告.md`，再由 `render-html` 渲染为 HTML 展示件）。
>
> 定位：**总结报告是整条流水线最核心的交付物**，HTML 完全依赖它。
> 质量不达标 = 整次 run 的对外价值归零。禁止产出"索引式速览"。

## 1. Gate 硬性门槛（不满足则 register-summary 拒绝）

- 8 个一级标题一字不差（`#` 一级标题）：核心结论速览 / 主干①·投资分析 /
  主干②·财报研读 / 主干③·行业分析 / 补充与参考 / 产物索引 / 数据截止日 / 仅供学习研究。
- 「产物索引」逐行列出 13 条相对路径原文（Gate 逐条字符串匹配，不可改写）。
- 「数据截止日」含 `数据截止日：<as_of>`；「仅供学习研究」含"仅供学习研究，不构成投资建议"。
- 字节 ≥ `SUMMARY_MIN_BYTES`（当前 2500）。
- 缺失/失败单元必须如实说明（来自 mark-failed 记录），不得隐瞒。

## 2. 质量升级要求（本项目标准，高于 Gate 下限）

1. **长文深度**：目标 25–40KB。每章 ≥4 个"论点→证据（标注来源产物）→推理→含义"的论证段落。
2. **≥6 张 markdown 表格**（必需集）：五年财务全景、ROE 多口径同业、行业比较、
   估值三情景、投资建议操作框架、新能源/替代格局。表后必须有"这说明什么"的推理。
3. **≥5 张 SVG 图示**：用 ` ```svg ` fence 内联 SVG 源码（渲染器已支持，见 §3）。
   必需集：ROE 多口径条形图、5 年自由现金流柱状图、估值三情景条形图、行业漏斗图、投资逻辑链框图。
4. **三大章节深化**：财报分析（五年全景 + ROE 双口径陷阱）、行业分析（横向排序 + 结构性变化）、
   投资建议（三情景 + 两级买点 + 加仓条件共振 + 立即排除线 + 强制重审节点）。
5. **冲突必须剖析**（不只列数字）：双口径差异、对冲效应、现金流真相、数据缺口、双源冲突，
   每条给出"这意味着什么"。
6. **正反两面**：优点与缺陷并陈，再解释为何优点不足以翻转结论。
7. **逻辑链贯穿**：生意→护城河→财务→行业→管理→估值→证伪→结论，章间有承接句。
8. **印章行**：核心结论速览含 `一句话总结：**<主句>——<副句>**`（HTML 提取为印章，主句含结论词）。

## 3. SVG 图示规范

- 渲染器（`tools/full_analysis_html.py`）支持 ` ```svg ` fence：内容原样内联（不转义），
  包在 `<div class="fig reveal">` 中；普通 ` ``` ` 代码块仍转义为 `<pre><code>`。
- SVG 源码必须 XML 良构：**正文中的 `<` `>` `&` 必须转义或改写**
  （如"全部 < 8%" 改写为"全部低于 8%"）。生成后先用 `xml.etree.ElementTree.fromstring` 校验。
- 推荐流程（防抄写错误）：熔炼 Agent 在 md 中放占位符 `%%SVG_N%%`（各一次），
  主流程用 Python 脚本把生成好的 `.svg` 文件机械替换进占位符，再 register。
- 配色与页面主题一致：terra `#B85235`、trust `#1B365D`、green `#2F6F4E`、warn `#9A5A2D`、
  ink `#26231C`；viewBox 宽度 680 与正文栏匹配。A 股惯例：**红=涨/正，绿=跌/负**。

## 4. 数字溯源（不可协商）

- 每个数字必须能在 13 份产物原文中找到；产物没有的用"—"，严禁估算/编造/外推。
- 交付前抽查 ≥20 个高特异性数字（逐年营收/净利/ROE/FCF、同业对比值、隐含收益率等），
  用 `grep`/Python 在 run_root 全文匹配，全部 FOUND 才算通过。

## 5. 渲染后验收（render-html 之后必做，不能只看字节数）

1. `<main>` 内 `<section>` 数 ≥ 8 且正文非空（曾发生解析器只认 `##` 导致空壳的 bug，已修）。
2. `<svg>` 元素数 = md 中 svg fence 数；`<table>` 数 ≥ 6；无 `&lt;svg`（转义残留）。
3. 导航 `<nav>` 链接数 = section 数。
4. 关键论断抽查（结论词 / 关键比率 / 截止日 / 免责声明）全部在 HTML 中出现。
5. 有条件时用浏览器/截图目测图表渲染效果。

## 6. 相关代码与命令

- 渲染器：`tools/full_analysis_html.py`（`_parse_sections` 支持 `#`/`##`；`_render_blocks` 支持 svg fence）。
- 登记：`python3 scripts/full_analysis.py register-summary --run-root <abs> --summary <abs>`（**必须绝对路径**）。
- 渲染：`python3 scripts/full_analysis.py render-html --run-root <abs>`。
- 改渲染器后跑 `bash scripts/check.sh` 并读取真实退出码。
